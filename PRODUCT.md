# Product

## Register
brand

## Users
Developers, research readers, and potential collaborators visiting Awan Smith's GitHub profile and personal portfolio.

## Product Purpose
Present Awan's Web3 and AI interests, technical writing, current work, and contact links. Maintain a reliable GitHub profile alongside a standalone React website, as requested by the owner.

## Brand Personality
Curious, expressive, technical. Carry the existing navy and pink identity into an interactive, visually ambitious portfolio inspired by React Bits.

## Anti-references
Broken remote image walls, repeated headings, invented achievements, and decorative effects that obscure the content.

## Design Principles
- Keep the owner's existing biography and writing as the source of truth.
- Use a distinctive interactive visual to invite exploration.
- Keep navigation and contact access immediate.
- Let README work independently of the React website.

## Accessibility & Inclusion
Provide keyboard navigation, legible contrast, responsive layouts, reduced-motion support, and a manual motion toggle. These are implementation defaults; no additional user-specific needs were supplied.
